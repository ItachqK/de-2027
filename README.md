# ДЭ-2027 — проект по теме

Веб-версия генератора из тренажёра ДЭ-2027. Открывается на любом устройстве:
телефон, планшет, ноутбук. Ничего устанавливать не нужно.

**Страница:** https://itachqk.github.io/de-2027/

## Что делает

Вводите тему — например «Обмен книгами» или «Пицца на районе» — и получаете:

- 11 глав от `composer create-project` до защиты, с временем на каждую;
- все команды и полный код 39 файлов: миграции, модели, контроллеры, Blade, CSS, тесты, README;
- проверки после каждой главы и типичные ошибки, которые стоят баллов;
- чек-лист на 75 баллов по КИМ 09.02.07-3-2027;
- речь для защиты, порядок демонстрации и ответы на вопросы;
- скачивание инструкции в `.md` и готового проекта в `.zip`.

Генератор работает целиком в браузере: подстановка темы, сборка архива и текста
идут на устройстве. Сервер нужен только чтобы отдать три файла страницы.

## Как генератор понимает тему

Это не ИИ и не «угадывание». Внутри — словарь из 32 предметных областей и
шаблоны с токенами:

1. Тема приводится к нижнему регистру и разбивается на слова.
2. Побеждает самый длинный ключ словаря, а совпадение с первым словом темы
   получает приоритет: «Курсы маникюра» — обучение, а не салон.
3. Короткие ключи (до 4 букв) срабатывают только с начала слова и с падежным
   окончанием — поэтому «Космический туризм» не превращается в тур, а
   «Столовая» — в СТО. Длинные ключи ищутся и внутри слова: «ветклиника» →
   клиника.
4. Из пресета берутся объект заявки, варианты, подпись даты, три статуса,
   два способа оплаты и текст отзыва.
5. Если совпадения нет — подставляются нейтральные формулировки: «услуга»,
   «Новая → Заявка принята → Завершено», «отзыв о качестве услуги».
6. Дальше 39 шаблонов прогоняются через подстановку `@@PROJECT@@`, `@@OBJECT@@`
   и остальных токенов. Структура проекта всегда одна — её требует КИМ:
   пользователи, заявки, статусы, отзывы, админка.

Поэтому любая тема даёт рабочий проект, но архитектура не меняется: меняются
названия, объект, статусы, оплата и текст отзыва.

Проверить подбор темы можно без браузера: `Blueprint::match()` в тренажёре и
`BPEngine` на странице используют один и тот же алгоритм, а тесты фиксируют
сложные случаи — составные слова, короткие ключи и темы вне словаря.

## Как это устроено

```
index.html            форма и каркас страницы
assets/style.css      оформление «бумага и чернила»
assets/engine.js      порт App\Support\Blueprint на JavaScript
assets/app.js         интерфейс: форма, результат, скачивание
assets/data.js        11 глав, 39 шаблонов, чек-лист, словарь тем
```

`assets/data.js` не пишется руками. Он выгружается из Laravel-тренажёра:

```bash
php tools/export-web.php "C:\путь\к\de-2027-web"
```

Скрипт берёт шаблоны из `resources/blueprints`, главы, чек-лист и речь —
и оставляет в них токены `@@PROJECT@@`, `@@OBJECT@@` и остальные.
Браузер подставляет значения под введённую тему.

После правок в `assets/` поднимите номер в `?v=20261114` внутри `index.html` — иначе браузер отдаст старую версию из кеша GitHub Pages.

Совпадение с PHP-версией проверено: `.md`, собранный в браузере, побайтово
равен `.md`, который отдаёт Laravel-тренажёр, а `.zip` открывается как обычный
архив с 39 файлами.

## Что внутри генерируемого проекта

Laravel + SQLite + Blade, две роли, заявки со статусами и отзыв после завершения:

- таблицы `users`, `bookings`, `reviews`;
- регистрация и вход по логину, пароли — хешем, CSRF, middleware;
- личный кабинет: только свои заявки, пагинация, пустое состояние;
- админка: все заявки, фильтр по статусу, переход только вперёд;
- отзыв один раз и только после завершения заявки;
- адаптив 390 / 768 / 1440 px, контраст, фокус с клавиатуры;
- 13 тестов: регистрация, доступ, заявки, статусы, отзывы.

## Локальный запуск

```bash
python -m http.server 8500
# или
php -S 127.0.0.1:8500
```

Открыть http://127.0.0.1:8500 — страница работает и без сети.
